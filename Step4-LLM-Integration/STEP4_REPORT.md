### 4.1 OllamaClient

**فایل**: `ollama_client.py` (350 خط)

```python
class OllamaClient:
    """کلاینت ارتباط با Ollama"""
    
    def is_available(self) -> bool:
        """بررسی دسترسی سرور"""
    
    def list_models(self) -> List[str]:
        """لیست مدل‌های موجود"""
    
    def generate(self, prompt, system_prompt, temperature=0) -> Dict:
        """تولید پاسخ"""
    
    def generate_stream(self, prompt) -> Generator:
        """تولید streaming"""
    
    def chat(self, messages) -> Dict:
        """مکالمه"""
```

#### ویژگی‌های کلیدی:

| ویژگی | توضیح |
|-------|-------|
| **Caching** | ذخیره پاسخ‌های تکراری |
| **Temperature=0** | خروجی یکنواخت |
| **Timeout** | 120 ثانیه پیش‌فرض |
| **Error Handling** | مدیریت خطاها |
| **Streaming** | پشتیبانی از streaming |

#### نمونه استفاده:

```python
from src.llm import OllamaClient

client = OllamaClient()

if client.is_available():
    response = client.generate(
        prompt="این پروپوزال را ارزیابی کن...",
        system_prompt="تو یک ارزیاب متخصص هستی.",
        temperature=0.0
    )
    
    print(response['content'])
```

### 6.4 نحوه استفاده

from src.llm import LLMAnalyzer

# ایجاد ارزیاب
analyzer = LLMAnalyzer(model="llama3.1:8b")
