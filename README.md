# Proposal-Evaluator
Offline intelligent evaluation system for Persian research proposals using LLMs and NLP
Persian Proposal Intelligent Evaluation System | Fully Offline & Sanction-Proof

Automated evaluation system for scientific research proposals that uses Large Language Models (LLMs) and NLP techniques to analyze proposals across multiple dimensions including writing quality, structure, content, references, and originality. The system detects plagiarism, generates comprehensive reports, and provides feedback for improvement.

Core Features:
- Fully offline with no internet dependency
- Complete data privacy and security
- Full Persian language support
- Microservices architecture with FastAPI
- Optimized ParsBERT & Sentence-BERT models
- Ollama & llama.cpp for LLM inference
- Easy deployment with Docker
- RESTful API with Swagger docs
