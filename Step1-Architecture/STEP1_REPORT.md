## 7. طراحی پایگاه داده

### 7.1 نمودار ER

```
proposals (1) ←──→ (1) evaluations
    ↓                      ↓
    │                      │
    ↓ (1)              (1) ↓
embeddings        evaluation_details
```

### 7.2 جداول و فیلدهای کلیدی

#### جدول 1: proposals

```sql
CREATE TABLE proposals (
    id SERIAL PRIMARY KEY,
    proposal_id VARCHAR(100) UNIQUE,
    file_name VARCHAR(255) NOT NULL,
    file_type VARCHAR(10),
    upload_date TIMESTAMP,
    status VARCHAR(20)
);
```

**تعداد فیلد**: 10  
**Index**: proposal_id, upload_date

#### جدول 2: evaluations

```sql
CREATE TABLE evaluations (
    id SERIAL PRIMARY KEY,
    evaluation_id VARCHAR(100) UNIQUE,
    proposal_id INTEGER REFERENCES proposals(id),
    final_score DECIMAL(5,2),
    writing_score DECIMAL(5,2),
    structure_score DECIMAL(5,2),
    content_score DECIMAL(5,2),
    references_score DECIMAL(5,2),
    originality_score DECIMAL(5,2),
    evaluated_at TIMESTAMP
);
```

**تعداد فیلد**: 13  
**Foreign Key**: proposal_id → proposals(id)

#### جدول 3: evaluation_details

```sql
CREATE TABLE evaluation_details (
    id SERIAL PRIMARY KEY,
    evaluation_id INTEGER REFERENCES evaluations(id),
    raw_text TEXT,
    normalized_text TEXT,
    sections JSONB,
    keywords JSONB,
    strengths JSONB,
    weaknesses JSONB,
    suggestions JSONB
);
```

**تعداد فیلد**: 12  
**JSONB Fields**: 6 (برای انعطاف‌پذیری)

#### جدول 4: embeddings

```sql
CREATE TABLE embeddings (
    id SERIAL PRIMARY KEY,
    proposal_id INTEGER REFERENCES proposals(id),
    embedding VECTOR(768),
    embedding_model VARCHAR(100),
    created_at TIMESTAMP
);
```

**تعداد فیلد**: 5  
**Vector Dimension**: 768 (Persian Sentence-BERT)

### 7.3 استراتژی Indexing

- **B-tree indexes**: proposal_id, evaluation_id, upload_date
- **GIN index**: JSONB fields (keywords)
- **IVFFlat index**: vector embeddings (similarity search)
